# Abbotsford snow estimates: share the scope, not just the link

**By the PlowWow team · October 27, 2026 · Snow Intelligence beta**

An Abbotsford council member gets a starting snow estimate, then sends the request-page link to the property manager. Will that link show the same address, figure and notes? In PlowWow’s current flow, the estimate draft is held in the browser session. Copying the page address does not create a shared property quote.

That detail matters when several people need to agree what a winter service request should cover. The useful handover is a reviewed description of the property and the work—not an assumption that everyone opening the same link will see the same draft.

## What the current request page actually carries

The public [estimate flow](/quote) can pass an address, estimate and scope notes into the optional request step. The current implementation uses route state and browser session storage for that handoff. It does not put those details into a shareable quote link.

Opening [the request page](/quote/request) in a fresh browser session without an estimate therefore offers a route back to the estimator. That is an empty draft, not evidence that a request has already been submitted or lost. If you want a different person to submit the enquiry, give them the agreed property information so they can review their own request.

The source currently treats an estimate draft as valid for less than 24 hours from its creation. That is a browser-draft rule, not a promise to hold a price, reserve route space or keep a quotation open for a day. Avoid using an unsubmitted browser draft as your long-term property record.

## An Abbotsford example: one manager, several decision-makers

Imagine a townhome council discussing a vehicle entrance, a shared walkway and a visitor-parking connection. This is a planning example, not a named customer's property. One member may have prepared an estimate while another is responsible for approving the final scope.

Before anyone sends the enquiry, agree which surfaces should be reviewed. Note where another party's responsibility begins, where a gate affects access and which entrance needs separate attention. Describe uncertainties as questions rather than guessing boundaries from the map. No resident access codes or private information should go into a document circulated widely.

For a larger site, the calculator's standard residential starting figure does not replace a tailored commercial or strata review. The useful output of the council discussion is a clearer enquiry—not a council-approved price based only on the screen.

## A handover the next person can use

Keep a short property brief with four parts:

- **Site:** the complete Abbotsford address and the property or building being discussed.
- **Requested scope:** the vehicle and pedestrian areas the team should review, with uncertainties marked.
- **Responsibility:** the person preparing the enquiry and the person who can approve an eventual proposal.
- **Open decisions:** access arrangements, snow-storage questions, timing needs and any work that belongs to another party.

If you record a displayed estimate for discussion, label it as a provisional starting estimate and keep its stated scope and date alongside it. Do not present the copied number as a confirmed PlowWow proposal. A screenshot or note is a discussion record, not a service agreement.

## A received request is another stage—not a booking

An estimate draft and a submitted request are different things. The application's received-request screen is designed to display a reference only after a successful submission. This article does not report a test customer submission or guarantee that a particular enquiry has been accepted.

After submitting a real enquiry, follow the confirmation shown to you and keep any reference the system provides. Confirm property scope, final price, service arrangements and current availability directly with PlowWow. Neither opening a page nor receiving a request reference confirms a crew booking.
